🔗 Configurar link dos QR codes

Este é o endereço que os QR codes vão gravar. Use o link publicado desta página de leitura (ex.: https://...). O painel acrescenta sozinho ?iop= ou ?mat= para abrir filtrado.

Se você abrir esta página já publicada na web, o painel preenche esse campo automaticamente com o endereço atual — só confirme e salve.

Enquanto o campo estiver vazio, os QR codes aparecem apenas como aviso (abrir o arquivo direto do computador, pelo caminho do disco, não gera link válido para o celular).

🔗 Sincronização — Google Sheets

Esta é a versão somente leitura. Ela apenas puxa os dados da planilha — nunca grava, nunca altera e nunca apaga nada no Sheets. Nenhuma edição feita aqui chega à planilha.

O painel já vem com a URL do Web App embutida no código: ao abrir, ele sincroniza sozinho, e volta a sincronizar a cada 5 minutos. Apague o campo e salve apenas se quiser desativar a sincronização neste computador.
